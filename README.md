# 📚 Bookstore Manager

A lightweight and responsive **Bookstore Management System** built using Node.js, Express.js, HTML, CSS, and JavaScript. It allows users to efficiently manage book inventory through CRUD (Create, Read, Update, Delete) operations.

## ✨ Features

- 📖 View all books in the inventory
- ➕ Add new books
- ✏️ Update book details
- 🗑️ Delete books
- 📱 Responsive and user-friendly interface
- 🔗 RESTful API endpoints built with Express.js
- ⚡ Lightweight and easy to run locally

## 🚀 Getting Started

Follow these steps to run the project locally.

### Prerequisites

Make sure the following are installed:

- [Node.js](https://nodejs.org/) (v18 or higher)
- npm
- Git

### 1. Clone the Repository

```bash
git clone https://github.com/arundodamani27/bookstore_manager.git
```

### 2. Navigate to the Project Directory

```bash
cd bookstore_manager
```

### 3. Install Dependencies

```bash
npm install
```

### 4. Start the Application

```bash
node server.js
```

If `index.js` is configured as the entry point, run:

```bash
node index.js
```

### 5. Open in Browser

Visit:

```text
http://localhost:3000
```

The Bookstore Manager application should now be running.

## 🔌 CRUD Operations

| Operation | Description |
|---|---|
| **Create** | Add new books to the inventory |
| **Read** | View the available books |
| **Update** | Edit existing book information |
| **Delete** | Remove books from the inventory |

## 🌐 Deployment

Since this application uses a Node.js and Express.js backend, it requires a hosting platform that supports Node.js applications.

Recommended platforms:

- [Render](https://render.com/)
- [Railway](https://railway.com/)

> **Note:** GitHub Pages supports static websites only and cannot run the Express.js backend.
