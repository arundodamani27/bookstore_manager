# Bookstore Manager

A lightweight web-based Bookstore Management application built with Node.js, Express, and vanilla HTML, CSS, and JavaScript.

## Features
- View, add, update, and delete book inventory records
- Clean, responsive frontend served from `public/`
- RESTful backend endpoints powered by Express

## Tech Stack
- **Backend:** Node.js, Express
- **Frontend:** HTML5, CSS3, JavaScript
